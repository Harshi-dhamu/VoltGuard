# VoltGuard

## OT Security Monitoring & AI-Assisted Threat Detection Platform

VoltGuard is an industrial/Operational Technology (OT) security platform designed to monitor industrial network activity, detect suspicious behavior, analyze security events, and provide centralized visibility through a desktop security dashboard.

The platform is designed around modular security components that communicate through a shared event-driven architecture.

---

## Overview

Modern industrial environments contain critical assets such as PLCs, industrial controllers, sensors, and communication systems. Security incidents in these environments can affect both digital infrastructure and physical processes.

VoltGuard provides a centralized security monitoring environment that helps security teams:

- Monitor industrial network traffic
- Track connected OT assets
- Detect suspicious or anomalous activity
- Monitor security alerts
- Track security decisions
- Analyze security events
- Monitor communication between security modules
- View live integration events
- Maintain centralized security visibility

---

## Key Features

### Security Dashboard

The VoltGuard dashboard provides a centralized interface for monitoring the overall security state of the OT environment.

Features include:

- Security overview
- System status
- Security metrics
- Recent activity
- Protection status
- Module integration status

---

### Traffic Monitoring

The Traffic Monitor provides visibility into network activity.

It supports monitoring of:

- Network traffic
- Protocol information
- Source and destination information
- Allowed traffic
- Blocked traffic
- Traffic statistics

---

### Asset Monitoring

The Assets section provides visibility into monitored industrial assets.

Example assets include:

- PLCs
- Industrial controllers
- Network devices
- OT infrastructure

The interface provides information about asset status and availability.

---

### Security Alerts

The Alerts module provides centralized visibility into detected security events.

Alerts can include:

- Critical events
- High-severity events
- Medium-severity events
- Suspicious network activity
- Process anomalies
- Security violations

---

### Security Decisions

The Decisions module provides visibility into security decisions generated by the platform.

Examples include:

- ALLOW
- BLOCK
- DROP
- Policy-based decisions

---

### Event Logs

The Event Logs module provides a centralized view of security-related events generated throughout the platform.

---

### Security Operations

The Security Operations interface provides a consolidated view of recent security activity.

It receives events through the shared event bus and displays:

- Event source
- Event message
- Event severity
- Recent security activity

---

### Incident Center

The Incident Center provides a dedicated interface for viewing and managing security incidents.

---

### Security Analytics

The Security Analytics module provides a centralized interface for analyzing security-related information and system activity.

---
